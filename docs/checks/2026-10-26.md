- **무엇**: `pypdf` 6.21.1 에 서비스 거부(DoS) 취약점 3건(CVE-2026-115572 / 115585 / 115580). 모두 **악의적으로 만든 PDF 를 열 때 긴 실행 시간**으로 멈추게 하는 유형이고, 6.21.2 에서 고쳐졌다. 원격 코드 실행·정보 유출은 아니다(가용성만).

### 3-1. 첨부만 다시 올리기 (`claims/reattach.py` 신설)

보완요청·임시저장된 **기존** 청구서를 열어 첨부문서를 지우고 폴더의 지금 파일을 다시 올려 [저장] 하는 기능(담당자 2026-10-23 "보완요청 와서 파일만 다시 올려달라고").

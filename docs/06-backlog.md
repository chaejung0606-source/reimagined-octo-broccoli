## A. 규정값이 없어 꺼져 있는 것 — 사용자 확인 필요

L3(규정·한도) 규칙은 값을 모르면 판정할 수 없다. 엔진이 `enabled_if` 로 꺼 두고
결과에 **'규정값 미설정'** 으로 남긴다. 아래 값을 받으면 앱의 [검토 기준] 화면에서
바로 넣을 수 있고, 넣는 즉시 해당 규칙이 켜진다. **코드 수정은 필요 없다.**

1. **근로장학금 지침** — 1일/월 근로시간 한도, 유형별 기준단가, 휴일근로 허용 여부
   → `R-SCH-017` `R-SCH-018` `R-SCH-019` `R-SCH-020`
2. **혁신인재지원금 지침** — 240,000원이 정액인지 시간급인지, 소학회 최소 인원
   → `R-INN-004` `R-INN-016`
3. **강원대 여비 규정** — 일비·식비·숙박비 한도, 자가용 km당 단가,
   공용차량 이용 시 정산 범위 → `R-TRV-025`~`R-TRV-028`
4. **동승 중복청구 처리 원칙** → `R-TRV-020`
5. **반려 기준선** — 🔴 1건이면 반려인지, 담당자 재량인지
6. **재학증명서 유효기간** — 지금은 서식에 적힌 **30일**을 기본값으로 쓰고 있다
   (`rules/common.yaml` 의 `enrollment_cert_valid_days`). 지침과 다르면
   [검토 기준] 화면에서 고치면 되고, 비우면 규칙이 꺼진다. → `R-CMN-013`

## C. 품질·운영

- **실제 서류로 돌려 본 적이 없다.** 개인정보 때문에 저장소에 넣을 수 없어
  `tests/conftest.py` 가 추출 결과를 직접 만들어 규칙만 시험한다.
  담당자 컴퓨터에서 실제 폴더로 한 번 돌려 보고, 오탐·미탐을 받아 와야 한다.
  **특히 아래 셋은 실제 데이터로 임계값을 맞춰야 한다.**
  - `R-TRV-014` 하이패스 경로 불연속 — 영업소 이름 표기가 영수증마다 달라
    (`대관령영업소` / `대관령(IC)`) 접미사를 떼고 비교한다. 표기가 더 갈리면
    `checks/travel.py` 의 `_gate()` 에 규칙을 더한다.
  - `R-TRV-024` 동시간대 상이한 장소 — 기본 60분(`conflict_window_minutes`).
  - `R-SCH-014` 강좌명 대사 — 부분일치 실패 시 유사도 0.6 으로 한 번 더 봐준다.
- **통장·재학증명서는 대개 스캔본이다.** 추출기는 붙였지만 텍스트가 없으면
  값이 비고, `R-CMN-013` `R-CMN-015` `R-CMN-016` 이 🔵 로 올라간다. 이것이
  의도한 동작이다 — 4단계에서 OCR 이 붙으면 그대로 판정으로 바뀐다.
  **다만 지급대상자 1명당 🔵 가 3건씩 늘었다.** 20명 묶음이면 60줄이다.
  전부 담당자가 눈으로 대조해야 하는 항목이라 틀린 표시는 아니지만, 실제로
  써 보고 '이만큼 보여도 괜찮은지' 를 확인해야 한다. 많다고 하면 방법은 둘이다 —
  4단계(OCR)를 앞당기거나, 화면에서 🔵 를 파일별로 접어 두거나.
- **UI 는 자동 검증이 없다.** PySide6 화면은 사람이 띄워 봐야 안다.
  CI 는 문법 검사(`compileall`)까지만 한다.
- **묶음 검토 성능** — 사람 수가 많으면 PDF 를 매번 다시 연다. 아직 느리다는
  보고는 없다. 느려지면 그때 캐시를 넣는다.

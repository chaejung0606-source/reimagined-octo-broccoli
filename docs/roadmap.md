## 1. 진단 모드 (다음 단계 실측용 도구) — 완료 (2026-10-13)

ERP 의 아무 화면이나 띄운 상태에서, 열린 모든 창/프레임의 URL 과 각 프레임 안의 입력 요소
(input/select/textarea/button/a)의 id · name · type · 가까운 라벨 · 현재값을
`~/.claim-downloader/_화면구조.txt` 로 저장한다. **읽기만. 아무것도 클릭하거나 값을 넣지 않는다.**

- `diagnose.py` + `session.capture_structure()`. 받기 화면 [진행 기록] 탭 구석의 **[화면 구조 저장]**
  (브라우저가 열려 있을 때), 콘솔은 `python -m claim_downloader --structure`.
- 비밀번호·파일 칸의 값은 남기지 않고(값을 읽는 칸 종류 허용 목록), 다른 값도 40자에서 자른다.
  결과 파일은 저장소·배포 zip 에서 제외. `tests/test_safety.py` 가 이 JS 가 읽기만 하는지 본다.
- 모의 결의서내역 화면으로 검증: 결의서 목록 프레임을 알아보고 `#btnDetail` · 행 체크박스가 나온다.
  **실제 ERP 결의서내역에서 CLAUDE.md 6절과 같은 결과가 나오는지는 담당자가 한 번 돌려 확인한다.**

# 01. 참고자료 분석 — 지출종류별 서류 구성

전달받은 샘플 2건(zip)을 전수 분석한 결과입니다. 검토 기준(02번 문서)은 전부 이 분석에서 도출했습니다.

---

## 1. 근로장학금

샘플에는 **성격이 다른 두 갈래**가 섞여 있습니다. 서류 세트가 다르므로 앱에서도 **하위 유형(subtype)으로 분리**해야 합니다.

### 1-A. TA형 (수업 조교) — 예: 권석재

| 서류 | 파일 | 텍스트 추출 |
|---|---|---|
| [양식1] TA 추천 및 서약서 | `26학년도 1학기 TA 기본서류(권석재).pdf` p1 | 가능 |
| [양식2] 개인정보 수집·이용 동의서 | 같은 파일 p2 | 가능 |
| [양식3] 신분증 + 통장 사본 | 같은 파일 p3 | **이미지** |
| [양식4] 재학증명서 | 같은 파일 p4 | **이미지** |
| [양식5] 근로장학생 근무상황부 | `2026년도 3월 TA 근무상황부.pdf` | 가능 |
| 지급내역 (사업단 작성, 대사용 마스터) | `2026년도 3월 (나)형 근로장학금 지급내역.pdf` | 가능(표) |

핵심 수치 흐름:
```
근무상황부  3/9·3/16·3/23 각 09:00~14:00 = 5h → 총 15h
지급내역    권석재 / 20,000원 × 15시간 = 300,000원
계좌        신한 110-493-878372  (양식2·근무상황부·지급내역 3곳에 중복 기재)
```

### 1-B. 서포터즈형 (데이터라이브러리 운영) — 예: 강옥일

| 서류 | 파일 | 텍스트 추출 |
|---|---|---|
| 장학금 지급 청구서 | `장학금 지급 청구서_강옥일.pdf` | 가능 |
| 월간 활동 결과 보고서 | `4월 월간 활동 결과 보고서_강옥일.pdf` | 가능(사진 포함) |
| [붙임2] 운영활동 보고서(근무일지) | `근무일지_강옥일(확인).pdf` | **손글씨 스캔** |
| [붙임1] 개인정보 동의서 + 신분증·통장·재학증명서 | `기본정보_강옥일.pdf` | p1 가능 / p2~3 이미지 |
| 지급내역 | `2026년 4월 (가)형 근로장학금 지급내역.pdf` | 가능(표) |

핵심 수치 흐름:
```
근무일지   4/7(4h) 4/?(4h) 4/13(5h) 4/15(3h) 4/20(4h) 4/27(5h) = 25h
           └ 2행 일자가 손글씨라 "4/8" 또는 "4/18"로 읽힘 → 판독 불확실 사례
청구서     활동기간 2026.4.7~4.30 / 청구금액 300,000원
지급내역   강옥일 / 12,000원 × 25시간 = 300,000원
```

시간 합계(25h)와 금액(300,000원)은 세 서류가 모두 일치합니다. 다만 근무일지의 학과 기재가
다른 서류의 `AI융합학과`와 달라 보이며(손글씨), 이런 항목은 **자동 판정 대신 "확인필요"로 올려야 하는
전형적인 사례**입니다.

> **(가)형 / (나)형 구분이 지급내역 파일명에만 존재**합니다. (가)형=서포터즈(12,000원/h), (나)형=TA(15,000~20,000원/h, 강좌별). 단가가 유형별로 다르므로 검토 규칙에서 유형을 먼저 확정해야 합니다.

## 2. 혁신인재지원금 (소학회 진행요원비)

예: AIMPACT / 김예린 (소학회 회장)

| 서류 | 파일 | 텍스트 추출 |
|---|---|---|
| [양식8] 혁신인재지원금 신청서 | `혁신인재_5월 AIMPACT_.pdf` | 가능 |
| [양식7-1] 월별 활동 결과 보고서 (1페이지 요약) | `활동보고서 (AIMPACT_5월).pdf` | 가능 |
| [붙임1] 근로장학생 근무상황부 | `근무상황부_AIMPACT_5월.pdf` | 가능 |
| 신분증·통장 사본, 재학증명서 | `기본정보(AIMPACT_김예린).pdf` | **이미지** |
| 지급내역 | `2026년도 5월 진행요원비(소학회 회장) 혁신인재지원금 지급내역.pdf` | 가능(표) |

핵심 수치 흐름:
```
근무상황부  5/6(3h) 5/6(5h) 5/13(3h) 5/20(5h) = 16h
신청서      지원금액 240,000원 (금이십사만원정)
지급내역    김예린 / 240,000원  → 240,000 ÷ 16h = 15,000원/h
계좌        신청서 "59220101565992" vs 지급내역 "592201-01-565992"  ← 표기형식 다름, 정규화 필요
```

구조적 특징: **소학회 단위 문서(활동보고서, 팀원 명단 20명)와 개인 단위 문서(근무상황부, 신청서)가 섞여** 있습니다. 회장 1인이 대표로 신청하므로 "신청자 = 지급내역의 회장 = 활동보고서의 회장"이 삼중으로 일치해야 합니다.

## 3. 출장비

11인(황승재·김동현·김민숙·방석훈·방주희·이동재·이성재·이세영·임채정·전상철·허아름)의 실제 정산 묶음입니다. **가장 서류 형태가 자유롭고 오류가 많은 유형**입니다.

### 서류 구성

| 서류 | 형태 | 비고 |
|---|---|---|
| 국내 출장신청서 | 전자결재 출력 PDF | 헤더가 `Handy`로 깨져 있어 일반 파서로 열리지 않는 파일 존재(`이성재/국내 출장신청서 (3건).pdf`) |
| 출장증빙 (표준 서식) | PDF | 3개 블록: `* 교통비 증빙` / `* 이동경로` / `* 체류 증빙 YYYY년 M월 D일` |
| 하이패스 통행료 영수증 | PDF (텍스트 추출 가능) | 여러 건 한 페이지에 나열 |
| 체류 영수증 (카드전표) | PDF / JPG / PNG 스캔 | **이미지, 회전·기울어짐 있음** |
| 근거자료 (강연정보 등) | 웹페이지 캡처 PDF | 이동재만 존재 |

### 출장증빙 서식 구조 (김동현 샘플 기준)

```
┌─────────────────────────────────────────────────────────┐
│ * 교통비 증빙                              18,000원      │
│   └ 하이패스 영수증 캡처 3장                             │
├─────────────────────────────────────────────────────────┤
│ * 이동경로   출발지→도착지 211km  도착지→출발지 154km    │
│              총 이동경로 365km                           │
│   └ 네이버 지도 경로 캡처                                │
├─────────────────────────────────────────────────────────┤
│ * 체류 증빙 2026년 6월 29일 월요일                       │
│   └ 현지 영수증 스캔                                     │
│ (출장 일자 수만큼 페이지 반복)                            │
└─────────────────────────────────────────────────────────┘
```

### 제출자별 실태 (검토 규칙 도출의 직접 근거)

| 제출자 | 이동경로 | 총 이동경로 | 교통비 | 체류증빙 | 관찰 |
|---|---|---|---|---|---|
| 김동현 | 211 / 154 | 365 ✅ | 18,000 | — | 출장신청서 2건(6/29~7/1, 7/3) — 어느 출장 정산인지 불명확 |
| 임채정 | 211 / 154 | 365 ✅ | 10,920 | 6/29·30, 7/1 ✅ | |
| 방주희 | 211 / 211 | 422 ✅ | 18,000 | 체류증빙 페이지 없음 | 별도 `방주희 교통 체류.pdf` 존재 |
| 이성재 | 206 / 206 | **미기재** ❌ | 8,500 | 6/29·30, 7/1 ✅ | 하이패스 8건 33,900원 중 **기간 내 3건 8,500원만 청구** — 정상이나 자동 대사 필요 |
| 이동재 | 82 / 82 | **미기재** ❌ | 4,350 | **7/2만** ❌ | 출장기간 7/2 18:00~7/3 12:00인데 하이패스 영수증은 **7/3 13:20** → 기간 초과 |
| 황승재 / 방석훈 / 이세영 | **블록 없음** ❌ | — | — | 6/29·30, 7/1 | 교통비·이동경로 블록 자체가 누락, 영수증은 별도 파일로 산재 |
| 허아름 | — | — | — | 별도 파일 | 하이패스 5건 15,500원 (6/29·6/30×2·7/3) / 출장기간 6/29~7/3 ✅ |
| 전상철 | — | — | — | 스캔 | `워크숍 출장증빙(전상철)-복사.pdf`와 `전상철 출장증빙.pdf` 2종 중복 |

### 이 표에서 바로 확인되는 문제 유형

1. **필수 블록 누락** — 교통비/이동경로 블록이 아예 없는 제출자 3명
2. **합계 미기재** — `총 이동경로` 칸 공란 2명
3. **기간 이탈 영수증** — 이동재의 7/3 13:20 통행료 (출장 종료 7/3 12:00)
4. **체류증빙 일자 누락** — 이동재 7/3분 없음
5. **영수증 묶음 ≠ 청구액** — 이성재 33,900원 제출 / 8,500원 청구 (기간 필터링 결과)
6. **파일 산재·중복** — 같은 증빙이 여러 파일로, 또는 `-복사` 파일 동시 제출
7. **동일 출장 다인 신청서** — `국내 출장신청서(6/29~7/1, 전상철 외 3인)`이 4명 폴더에 각각 복사되어 있음 → 동승 여부/중복청구 확인 필요
8. **PDF 구조 손상** — 전자결재 출력물 일부가 표준 파서로 열리지 않음

## 4. 서류 전반의 기술적 제약 (앱 설계에 직결)

| 항목 | 실태 | 대응 |
|---|---|---|
| 텍스트 레이어 | 한글 서식류는 대부분 추출 가능 | `pdfplumber`/`pypdf` 우선 |
| 표 구조 | 지급내역·근무상황부는 셀 순서가 뒤엉켜 추출됨 (예: 이름/학번이 표 하단에 몰림) | 좌표 기반 재조립 또는 Vision 모델 |
| 손글씨 | 근무일지(강옥일)는 **전면 손글씨** | OCR 불가 → Vision LLM 필수, 신뢰도 낮으면 "확인필요" 처리 |
| 스캔 이미지 | 체류 영수증은 회전·기울어짐 | 자동 회전 보정 후 OCR |
| 서명/날인 | `서명 또는 날인` 문구만 있고 실제 서명이 이미지 | 서명란 영역 픽셀 밀도 검사 + Vision 판정 |
| 개인정보 | 주민등록번호 13자리 전체가 평문 노출 | **전량 로컬 처리 필수**, 외부 API 전송 시 마스킹/사용자 동의 |
| 파일명 인코딩 | zip이 CP949로 압축됨 | 압축 해제 시 인코딩 폴백 필요 |

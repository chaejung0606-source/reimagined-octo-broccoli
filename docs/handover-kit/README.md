## 1. 한 줄로

**실측 → 문서 → 설계 확인 → (읽기 · 누르기를 나눈) 구현 → 모의 화면 + 안전 테스트 → 실제 1건 시험 → 기록으로 고침 → 되풀이.**

화면을 보지 않은 채 요소 이름을 추측해 만든 코드는 실제 화면에서 한 번도 그대로 돈 적이 없다. 반대로 담당자가 보낸 실측 파일 하나로
만든 코드는 대개 1~2번의 실제 시험 안에 됐다. 시간은 거의 전부 '추측' 과 '같은 id · 숨은 탭 · 가상 스크롤' 같은 함정(4절)에서 잃었다.

## 2. 원칙 — 어기지 않는다

1. **로그인은 사람이.** 아이디 · 비밀번호 · 쿠키(`storage_state` · `user_data_dir`)를 코드 · 설정 · 기록 어디에도 두지 않는다. 담당자가 채팅으로 비밀번호를
   주려 해도 받지 않는다 — 앱이 알아서 이어 가게 고치는 쪽으로 간다.
2. **되돌리기 어려운 단추는 앱이 누르지 않는다** — 제출 · 결재 · 신청 · 삭제 · 취소. 앱이 누르는 단추는 담당자가 **글로 허락한 것만**("네 눌러도 됩니다", 날짜),
   그 목록을 안전 테스트(`test_safety.py`)에 박아 허락 밖의 단추가 코드에 들어오면 테스트가 깨지게 한다.
3. **기본은 미리 보기(dry-run).** 실제로 넣는 것은 체크를 풀어야 하고, 넣기 전에 요약을 보이고 한 번 묻는다. 돈 · 결재가 걸린 입력은
   "앱이 임시저장까지, 사람이 검토하고 제출" 로만 만든다.
4. **확실할 때만 앱이, 애매하면 사람에게.** 후보가 0개 · 여럿이면 멈추고 화면에 노란 띠(사람 차례)와 [계속] / [멈추기]. 사람이 대신한 단계는 '제출 전 확인할 것' 에 남긴다.
5. **읽기 코드와 누르기 코드를 이름으로 나눈다** — `*_PROBE_JS`(읽기) · `CLICK_*_JS`(누르기) · 값 넣기는 한 모듈(`form.py`)의 `FIELDS` 에 적힌 id 만.
   안전 테스트가 누르는 상수의 수와 대상을 센다.
6. **개인정보 파일은 저장소에 올리지 않는다.** `.gitignore` + CI 혼입 검사 두 겹. 기록(로그)은 가린 사본으로 공유한다. 공개 저장소면 주소 · 열쇠도 문서 · 커밋에 적지 않는다.
7. **추측으로 문서를 바꾸지 않는다.** CLAUDE.md 는 실측 사실의 저장소 — 줄마다 `(실측 YYYY-MM-DD)` · `(추정)` · `(실제 확인 YYYY-MM-DD)` 을 붙이고,
   담당자의 말은 날짜와 함께 따옴표로 그대로 남긴다. 나중에 "왜 이렇게 만들었나" 를 찾는 유일한 길이다.
8. **앱이 화면에서 읽을 수 있는 값은 사람에게 되묻지 않는다**(목록 · 기간 · 번호) — 담당자 "이런 사소한 것까지 내가 확인하기엔 힘들어".

## 3. 절차 — 업무 하나를 자동화할 때까지

### 3-1. 업무 하나를 고르고, 사람의 클릭 순서를 글로

메뉴 → 화면 → 칸 → 단추 차례로 적는다. "여기서 [저장] 을 누르면 결재가 올라간다" 처럼 되돌리기 어려운 단추를 표시한다.
자주 하는 것 · 실수하면 비용이 큰 것부터. 한 번에 하나.

### 3-2. 화면 구조 저장 — `structure_capture.py`

```
pip install playwright
python -m playwright install chromium
python structure_capture.py https://kcloud.kangwon.ac.kr/websquare/websquare.jsp?w2xPath=/cm/main/index_tabControl.xml
```

브라우저가 뜨면 **사람이 로그인**하고 실측할 화면을 띄운 뒤 터미널에서 화면 이름을 적고 Enter — 화면마다 되풀이, `q` 로 끝.
`~/화면구조/화면구조_YYYYMMDD_HHMM.txt` 가 하나씩 생기고 `화면구조_모음.txt` 에 차례로 쌓인다 — **담당자는 모음 하나만 보낸다.**
이미 떠 있는 크롬에 붙으려면 `chrome.exe --remote-debugging-port=9222` 로 띄운 뒤 `--cdp http://localhost:9222`. `--site 호스트` 로 그 사이트 창만.

찍을 장면(차례대로, 모음 하나에):
1. 로그인 뒤 첫 화면(메뉴 · 탭의 글자와 id — 앱이 이동하려면 이것부터)
2. 업무 화면을 **빈 채로**(칸 id · 뜻 · 보기 값 · 필수 · 읽기전용)
3. 값을 하나 고른 뒤(종속 칸이 생기거나 잠기는지)
4. 팝업 · 돋보기를 연 채(별도 창이면 창으로 잡힌다 · 결과를 어느 처리기로 돌려주는지)
5. 검색 결과가 뜬 채(목록 제품 · 열 이름 · 줄을 고르는 방법)
6. 저장 직전과 직후(숨은 값 — 번호 · 상태 — 가 어떻게 바뀌는지, 화면이 다시 열리는지)

주의: 비밀번호 · 파일 칸은 안 적히지만 계좌번호 · 이름 같은 값은 섞일 수 있다 → **빈 작성 화면**에서, 보내기 전에 한 번 훑는다.
확인 창(alert)이 떠 있으면 닫고 Enter(떠 있으면 8초 뒤 '읽지 못함' 으로 남는다). 결과 파일은 저장소에 올리지 않는다.

### 3-3. CLAUDE.md 에 그 화면의 구조 절을 쓴다

적는 것: 창 · 프레임(주소 · 제목 · **내용으로 알아보는 표식** — 주소로 찾지 않는다) · 칸(id · 뜻 · 보기 값 · 필수 · 읽기전용 · 종속) ·
목록(제품 · 열 이름 · 행 선택 방법 · 가상 스크롤 여부) · 팝업(별도 창인지 · opener 로 돌아가는 처리기 이름) · 숨은 값(번호 · 상태) ·
**절대 누르지 않을 단추의 id · 글자**. 값(계좌 · 이름 · 번호)은 적지 않는다. 실측 파일 자체는 저장소에 올리지 않는다.

### 3-4. 설계 확인 — 담당자에게 물을 것

- 앱이 눌러도 되는 단추(글로 답을 받는다) · 어디까지 앱이 하고 어디서 사람이 넘겨받나
- 확실하지 않을 때(후보 0 · 여럿) 어떻게 할지 · 중복(이미 넣은 것) 판단 기준 · 입력 자료의 폴더 · 파일 모양
- 시험 방법 — `[시험]` 표시를 붙여 넣고 담당자가 지울 수 있는 상태(임시저장)까지만

### 3-5. 구현 규칙

- Playwright **동기 API**, 브라우저는 **스레드 하나**에서만(브라우저를 만든 스레드에서만 쓴다). 화면(UI)은 신호로 명령 · 결과를 주고받는다.
- 프레임은 주소가 아니라 **내용**으로 찾는다(같은 주소가 다른 화면을 그리고, 같은 화면이 다른 주소로 뜬다).
- 값 넣기는 `form.py` 의 `FIELDS` id 만, 누르기는 `CLICK_*_JS`, 읽기는 `*_PROBE_JS`. 누르기 JS 는 id 와 글자가 **둘 다** 맞고 **보이는** 요소 **하나**일 때만 누른다.
- 모든 단계가 기록(`_실행로그.txt`)을 남긴다 — 무엇을 읽었고 · 무엇을 눌렀고 · 결과가 무엇인지, 금액 · 건수까지. AI 는 이 기록으로만 고친다.
- 설정 · 기록은 사용자 홈(`~/.<앱>/`)에 둔다. 앱 폴더는 업데이트(git pull)가 갈아엎는다.
- 사람이 브라우저를 쓰는 동안(`hands_on`)은 확인 창을 손대지 않아 보이게 하고, 앱이 넣는 동안만 처리기가 닫는다.

### 3-6. 모의 화면 + 안전 테스트

실측 id · 모양 그대로 흉내 낸 HTML 을 로컬 서버로 띄워 **실제 Chromium** 으로 끝까지 돌리는 테스트를 둔다(같은 id 둘 · 가상 스크롤 · 저장 뒤 다시 열림 ·
팝업 · 확인 창까지 흉내). 안전 테스트(`test_safety_template.py`)는 누르는 대상 허용 목록 · 값 넣기 금지 · 로그인 정보 금지를 코드로 지킨다.

### 3-7. 실제 1건 시험

'앞 1건만' · `[시험]` 표시 · 임시저장까지. 담당자가 돌리고 기록 파일(가린 사본)을 보내면 그것으로 진단한다.
처음 실제 화면에서 한 번에 되는 일은 드물다 — 첫 evaluate 타이밍 · 숨은 탭 · 같은 id · ERP 가 되돌리는 값(4절). 두세 번의 왕복을 계획에 넣는다.

### 3-8. 되풀이 · 문서

실제로 되면 CLAUDE.md 에 `(실제 확인 YYYY-MM-DD, 담당자 "잘됩니다")` 를 적는다. 안 되면 기록의 줄을 인용해 까닭 · 고친 것을 적는다.

## 4. 기술 노하우 — ERP 에서 잃은 시간의 목록 (새 플랫폼에서도 먼저 의심할 것)

1. **첫 evaluate 타이밍** — 목록이 눈에 보여도 첫 `frame.evaluate()` 가 False · 예외. 화면 탐지는 반드시 재시도 고리(0.5초 × 40). 작성 화면도 한 번 보고 포기하지 않고,
   첫 실패 뒤 그 창을 앞으로 가져온다(`bring_to_front`).
2. **가상 스크롤** — 화면에 그려진 줄만 DOM 에 있다. 줄 번호로 바로 찾지 말고 **열쇠 값(문서번호)으로 스크롤하며** 찾는다. 결과 목록도 21줄만 읽히는 일이 있다.
   **숨은 탭 안의 목록은 높이 0** 이라 일부만 읽힌다 → 보이게 앞으로 가져온 뒤 읽고, 그래도 숨어 있으면 일부만 읽지 말고 멈춘다.
3. **같은 id 가 탭마다** — `getElementById` 는 문서에서 먼저 나오는 것을 준다. '같은 id 중 **보이는** 요소' 를 고른다. 숨은 [저장] 까지 세면 '여럿' 이 된다.
4. **팝업은 별도 창** — iframe 이 아니다. 결과를 opener 의 콜백으로 돌려주므로 **자기를 연 화면에만** 값이 간다. 앱이 연 팝업에는 표시를 붙여 구분하고,
   다른 화면에서 연 팝업이 남아 있으면 닫고(창 닫기) 새로 연다. 닫히는 중인 창이 목록에 남아 있을 수 있다.
5. **확인 창(alert · confirm)** — Playwright 는 처리기가 없으면 **띄우지 않고 바로 닫는다**(confirm = 취소). 사람이 쓰는 동안은 처리기를 두되 손대지 않아야 보인다.
   확인 창이 떠 있는 동안 `evaluate` 는 멈춘다 — 쉬는 동안의 '창이 닫혔나' 확인은 스크립트를 돌리지 않는 왕복(`wait_for_timeout(1)`)으로.
6. **프레임은 내용으로** — URL 로 찾지 않는다. 작성 화면과 상세 화면이 같은 페이지라 같은 링크('출력')가 둘 다 있을 수 있다.
7. **다운로드** — 보고서 팝업은 `expect_download` + `save_as` 로 파일 이름을 직접 정한다. 파일 링크는 `request.get` 이 HTML 을 주기도 한다 → 화면 안 `fetch`(같은 출처 · Referer)
   → 사람처럼 링크를 눌러 `expect_download` 차례. **Content-Type 을 믿지 않는다**(진짜 PDF · 사진에도 `text/html`) — 몸통 앞글자(`%PDF` · `<!doctype`) · 매직 바이트로.
   눌러 받은 파일은 브라우저 임시 폴더에 남으니 옮긴 뒤 지운다.
8. **목록 제품마다 읽는 법이 다르다** — JGM(`class k_열이름` · `.jgrid-row` · `title` 속성이 원본 값) · IBSheet 8(`getDataRows()` · `getValue(줄, 열)` · `Cols`, 대문자 `Get…` 은 바탕 TreeGrid) ·
   th 표 · role=grid. 스크립트 객체가 있으면 **DOM 보다 스크립트로** 읽는 쪽이 정확하다(고정 열 · 가로 스크롤로 DOM 이 나뉜다). 행 라디오의 onclick 번호는 줄 번호가 아니다.
   줄 고르기는 `setValue(줄,'chk',1)` 같은 제품 API 가 [상세] 단추의 처리기(`getRowsByChecked`)와 맞아야 한다 — 처리기 글을 읽어 확인한다.
9. **저장 성공 판정은 실측한 값으로** — 추측한 값(`REQ_SEQ_NO` 바뀜)이 아니라 실측(`#REQ_CNT` 생김 · 진행구분 40). 저장 뒤 화면이 **다시 열리고** 입력 칸이 비워지며
   탭이 처음으로 돌아간다 — 다음 줄을 넣으려면 탭부터 다시. 저장 뒤 줄 수가 늘었는지 · 번호가 그대로인지로 '고침' 과 '새 줄' 을 가린다.
10. **고르기 칸(select) 맞추기** — 정확히 같은 보기 → 몸통(앞말 · '은행' 뗀 것) → 앞부분 → 포함. 정확히 같은 것이 아니면 **맞는 보기가 하나일 때만** 고른다.
11. **플랫폼이 되돌리는 값** — 소득자를 고르자 소득구분이 되돌아갔다. 넣은 값은 **저장 직전에 다시 보고** 다르면 다시 고른다. 그래도 안 되면 저장하고 '확인할 것' 에.
12. **멈춤(freeze) · 세션** — 재접속 때 로그인이 살아 있으면(같은 묶음의 쿠키) 사람을 부르지 않고 잇는다. 화면이 안 뜨는 것이 아니라 그 건에 그 화면이 **없는** 것일 수 있다 →
    10초 그대로면 건너뛰고 '받지 않는 것' 목록에 넣는다. 무활동 30분 · 창 닫음 · 앱 끔이면 앱이 [로그아웃] 을 눌러 세션을 끝낸다(허락 받고).
13. **브라우저** — `new_context(no_viewport=True)` 아니면 화면이 1280×720 에 묶인다. 마지막 창을 닫아도 브라우저는 살아 있다. 창이 닫혔는지는 2초마다 가벼운 왕복으로.
    `browser.new_page()` 의 묶음에는 새 탭을 못 연다 — `new_context()` 로.
14. **셀렉터** — id 없는 단추는 글자로(정확히 일치 · 보이는 것 하나), 메뉴 · 탭은 `cursor: pointer` 글자. jQuery 로 붙인 처리기(`jQuery._data(el,'events')`)를 읽으면 무엇을 부르는지 안다.
15. **날짜 범위 한도 · 쪽 넘김 · 거르기** — 조회가 2년까지만 되면 창을 나눠 합친다(같은 번호는 한 번만). 목록에 안 보이면 **거르기('전체')** 부터 의심하고 쪽 번호로 끝까지.
16. **기록 가리기** — 주민번호 · 계좌(끝 4자리만) · 학번 · 전화 · 메일 · 이름을 가린 사본으로 공유. 제어 문자(NUL)가 섞이면 클립보드가 끊긴다 → 걷어낸다. 과제번호 같은 열쇠는 남긴다.
17. **윈도우** — `.bat` 는 CP949 · `chcp` 금지 · 줄표(—) 금지, `.ps1` 은 UTF-8 BOM, `.gitattributes` 에 `* -text`, git 호출은 `CREATE_NO_WINDOW` · `-c core.autocrlf=false`.
    Qt 앱이면 글꼴을 묶어 두고(TrueType), 드롭다운 위 휠이 값을 바꾸지 않게 한다.
18. **배포 = 푸시** 면 CI 가 막아야 한다 — 테스트 · 문법 · 이름 오류(ruff F821 등, 단추를 눌러야 터지는 NameError 가 배포됐었다) · 개인정보 혼입. 의존성이 바뀌면 준비 표시 판을 올린다.

## 5. WebSquare(K-Cloud)에서 미리 보이는 것 — 실측 전, 전부 추정

- 주소 `websquare.jsp?w2xPath=/…/화면.xml` — 화면이 XML 로 정의되고 프레임마다 `w2xPath` 가 화면 이름 역할을 한다. 도구는 프레임 줄에 `<== w2xPath …` 로 적는다.
- 요소 id 가 `mf_wfm_…` 처럼 길고 화면마다 앞부분이 같다 → id 끝부분 + 글자 · 라벨로 찾는 길도 둔다.
- 목록(gridView)의 DOM 과 API(`$p.getComponentById(id)` · `getRowCount()` · `getCellData(행, 열)` 꼴로 알려져 있다)는 **실측해야** 한다 — 도구의 `틀:` 줄(판 · w2 요소 종류 수)과
  `role=grid` 표 줄로 먼저 보고, IBSheet 때처럼 첫 실측 뒤 도구에 그 제품의 스크립트 읽기를 더한다.
- 탭(`index_tabControl`)으로 여러 화면이 한 창에 — ERP 의 '숨은 탭 = 높이 0' 과 같은 문제를 의심한다.
- 로그인 · SSO 는 사람. `authKey` · `token` 값은 도구가 가린다.

## 6. Claude(AI)와 일하는 법

- AI 는 사이트에 들어갈 수 없다(로그인은 사람 · 클라우드 세션에서는 그 주소에 닿지도 않는다). **담당자가 실측 파일 · 기록 파일을 주고 AI 가 코드를 고친다** — 이 왕복이 전부다.
- **CLAUDE.md 가 기억이다.** 새 세션은 그것부터 읽는다. 맨 위에 "추측으로 바꾸지 않는다". 화면마다 절을 두고, 담당자의 말을 날짜 · 따옴표로 남긴다(결정 · 허락 · 정정 모두).
- 한 번에 하나의 화면 · 하나의 단추 허락. "눌러도 됩니다" 를 받은 날짜를 적고 안전 테스트에 그 단추를 넣는다.
- 기록 보내기를 한 단추로(가린 기록을 구글 시트 Apps Script 웹 앱에 — AI 는 환경 변수의 읽기 주소로 읽는다). 처음엔 파일 복사로 시작해도 된다.
- 커밋은 **한국어 한 줄**(무엇을 왜). 푸시가 곧 배포면 CI 가 막는다. 커밋 · 코드 · 문서에 주소 · 열쇠 · 모델 이름을 적지 않는다.
- AI 가 만든 것은 모의 화면 · 테스트로 먼저 검증하고, **실제 확인은 담당자가 1건으로**. "됐다" 는 담당자의 말과 기록으로만 적는다.

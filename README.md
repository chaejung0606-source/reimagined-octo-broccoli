# ERP 청구서 다운로더

강원대 ERP 에서 **승인된 청구서(지출요구 및 결의서) PDF 를 자동으로 받아, 내용에 맞는 이름을 붙여
비목 폴더에 넣어 주는** 데스크톱 앱입니다. 이미 받은 건은 문서번호로 가려 건너뜁니다.

이 앱은 **받기만** 합니다. ERP 에 무언가를 입력하거나 제출하지 않습니다.
아이디·비밀번호는 어디에도 저장되지 않습니다. 매번 앱이 연 브라우저에서 직접 로그인합니다.

## 처음 한 번만 (설치)

1. **Python 설치** — https://www.python.org/downloads/
   (설치 첫 화면에서 "Add python.exe to PATH" 체크)
2. 이 폴더의 **`앱 실행.bat`** 을 더블클릭합니다.
   필요한 것(화면 라이브러리 · 자동 조작용 브라우저)을 받느라 처음에는 5~10분 걸립니다.
   끝나면 앱이 뜨고, 바탕화면에 **[ERP 청구서 다운로더]** 아이콘이 생깁니다.
3. 앱의 **[설정]** 에서 저장 폴더를 고릅니다 — 비목 폴더(01. 인건비 · 02. 장학금 …)가 바로 아래
   있는 폴더입니다. 예) `C:\Users\…\지출결의서\2026년도(e나라도움)`

## 사용 방법 (매번)

1. 바탕화면 아이콘으로 앱을 엽니다.
2. **① 브라우저 열기** → 앱이 보관 폴더를 훑은 뒤 ERP 창을 엽니다.
3. **그 브라우저 창**에서 ERP 로그인 → [과제관리 → 과제정보 → 청구서] → 결의서내역 목록을 띄웁니다.
   (평소 쓰는 Edge/크롬이 아니라, 앱이 새로 연 창이어야 합니다)
4. 앱으로 돌아와 **② 목록 읽기** → 받을 건이 표에 뜹니다.
5. 숫자가 맞으면 **③ 모두 받기**. 처음이면 **앞 1건만 시험** 으로 흐름부터 확인하세요.
   대상이 수십 건 이상이거나 `⚠⚠` 경고가 뜨면 취소하고 저장 폴더를 확인하세요.

받은 파일은 **각 비목 폴더 바로 아래**에 들어갑니다. 예산관리 플랫폼에 올린 뒤 `업로드/` 폴더로
옮기세요. 앱은 `업로드/` 폴더를 읽기만 하고 절대 건드리지 않습니다.

### 파일명 형식

`비목번호_(지출예정일 YYMMDD) 적요_이체자_(금액).pdf`
예) `09_(261008) 2026년 사업단 정수기 임차료(9월)_코웨이(주)_(51,900).pdf`

[설정] 에서 비목 번호를 빼고 날짜로 시작하게(`(261008) …`) 바꿀 수 있습니다.

## 문제가 생기면

- 받기 화면 아래 **진행 기록**에 어디까지 됐는지 나옵니다. [로그 파일 열기] 로 `_실행로그.txt` 를
  열어 담당자(임채정)에게 보내 주세요.
- "결의서내역 목록을 찾지 못했습니다" → 앱이 연 브라우저 창에서 목록을 띄웠는지 확인
- 주황색 띠 "상세화면이 멈춰…" → 그 브라우저에서 다시 로그인 → 목록 → [계속] (같은 건부터 이어받습니다)
- 처음부터 다시 받고 싶으면 [설정 → 기록 → 폴더 열기] 에서 `_받은기록.json` 을 삭제
  (보관 폴더에 있는 건은 그래도 건너뜁니다)

## 업데이트

새 기능이 올라오면 앱의 **[업데이트]** 화면에서 [업데이트 확인] → [업데이트 적용] 을 누르고
앱을 다시 시작합니다. 설정과 받은 기록은 앱 폴더 밖(`사용자 폴더\.claim-downloader`)에 있어
업데이트해도 그대로 남습니다.

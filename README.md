# 지출 서류 자동 검토 데스크톱 앱

지출종류를 고르고 서류를 업로드하면, **기준에 따라 검토해서 수정할 부분을 정리해 알려주는** 앱.

대상 지출종류: **근로장학금** · **혁신인재지원금** · **출장비**

현재 **1~3단계(문서 분류 → L0 완비성 → L1 내부 계산 → L2 교차 대사)가 OCR 없이 동작**합니다.
샘플에서 실제로 발견된 오류의 대부분이 여기서 잡힙니다.

---

## 빠르게 써 보기

```bash
pip install -r requirements.txt

# 서류 폴더(또는 zip) 하나를 검토한다
python -m app review 서류폴더 --type 출장비
python -m app review 강옥일 --type 근로장학금 --subtype SUPPORTERS

# 제출자에게 그대로 보낼 수정 요청서
python -m app review 서류폴더 --type 출장비 --format md --out 수정요청서.md

# 파일이 무슨 서류인지만 판정
python -m app classify 서류폴더 --type 혁신인재지원금

# 추출된 원문 확인 (실제 서식에 맞춰 패턴을 조정할 때)
python -m app dump 서류폴더

# 적용될 규칙과 설정값 확인
python -m app rules --type 출장비
```

`review` 는 🔴 수정 필요가 하나라도 있으면 종료코드 1을 돌려줍니다.

### 출력 예

```
[R-TRV-006] 🔴 수정 필요 총 이동경로 합계 오류·공란
  층위    L1 문서 내부 정합성
  내용    총 이동경로((공란))가 편도 합계(82+82)와 다르거나 비어 있습니다.
  근거    출장증빙 (교통비·이동경로·체류)
  검출값  출발지→도착지 거리 = 82
  검출값  총 이동경로 = (공란)
  조치    총 이동경로 칸에 164km 를 기재하세요.
```

`조치` 는 **계산된 정답까지 담은 완결된 문장**입니다. 그대로 복사해 보내면 됩니다.

## 설계 요약

### 기준을 4개 층위로 나눈다

| Layer | 질문 | 예 | 현재 상태 |
|---|---|---|---|
| **L0** 서류 완비성 | 낼 게 다 왔나 | 재학증명서 누락, 교통비 증빙 블록 없음 | ✅ 동작 |
| **L1** 문서 내부 정합성 | 그 서류 하나만 봐도 틀렸나 | 09:00~14:00인데 6시간, 총 이동경로 공란 | ✅ 동작 |
| **L2** 문서 간 교차 정합성 | 서류끼리 말이 맞나 | 근무상황부 15h vs 지급내역 20h | ✅ 동작 |
| **L3** 규정·한도 | 지침을 넘었나 | 월 근로시간 초과, 재학증명서 1개월 경과 | ⚪ 지침 수치 입력 시 자동 활성 |

### 판정은 4단계 — "위반/정상" 2분법을 쓰지 않는다

🔴 수정 필요 · 🟡 확인 요망 · 🔵 **판독 불가** · 🟢 이상 없음 (+ ⚪ 미검사)

손글씨 근무일지·회전된 영수증 스캔이 섞여 있어, 추출 신뢰도가 낮으면
판정 대신 **🔵 판독 불가**로 올려 사람이 확인하게 합니다. 이 장치가 없으면 오탐으로 앱을 못 씁니다.

**"비어 있음"과 "못 읽음"은 다릅니다.** 칸을 찾았는데 값이 없으면 🔴(총 이동경로 공란),
칸 자체를 못 읽었으면 🔵 입니다. 이 구분이 앱의 신뢰도를 좌우합니다.

아직 못 보는 검사(서명 유무, 신분증 마스킹, 스캔 품질)는 조용히 통과시키지 않고
**⚪ 이번 단계 미지원**으로 남겨 사유를 함께 표시합니다.

### 지출종류별 핵심 축

| | 검토의 중심 | 가장 어려운 부분 |
|---|---|---|
| 근로장학금 | `시간 × 단가 = 금액` 삼중 대사 | 손글씨 근무일지 (4단계) |
| 혁신인재지원금 | 소학회명·회장·지도교수 3자 일치 | 20인 팀원표 추출, 본문에서 활동일 추출 |
| 출장비 | 영수증 ↔ 출장기간 ↔ 이동거리 | 이미지 영수증 OCR (4단계), **기간 필터 후 합산** |

### 샘플에서 실제로 검출되는 문제

회귀 테스트(`tests/test_engine.py`)가 아래를 전부 고정해 두고 있습니다.

| 사례 | 규칙 | 결과 |
|---|---|---|
| 이성재·이동재 — `총 이동경로` 공란 | R-TRV-006 | 🔴 + "164km 를 기재하세요" |
| 황승재 — 교통비·이동경로 블록 누락 | R-TRV-002/003 | 🔴 |
| 이동재 — 출장 종료 7/3 12:00, 통행료 7/3 13:20 | R-TRV-011 | 🔴 |
| 이동재 — 체류 증빙 7/3 누락 | R-TRV-004 | 🔴 |
| 김동현 — 신청서 1장에 출장 2건 | R-TRV-017 | 🟡 |
| AIMPACT — 보고서 활동일 5/4·5/18 ≠ 근로일 5/6·5/13·5/20 | R-INN-012 | 🟡 |
| 팀원 학번 8자리 | R-INN-014 | 🟡 |
| 본문 오탈자 `5원 4일` | R-INN-020 | 🟡 |
| **이성재 — 하이패스 8건 33,900원 중 기간 내 3건 8,500원** | R-TRV-009 | 🟢 (기간 필터 후 일치) |
| **김예린 — 계좌 `59220101565992` vs `592201-01-565992`** | R-CMN-005 | 🟢 (정규화하면 동일) |
| **권석재 · 강옥일 — 시간·단가·금액 3서류 일치** | R-SCH-008~010 | 🟢 (무오탐) |

마지막 세 줄이 중요합니다. **정상 건에서 조용해야** 담당자가 이 앱을 씁니다.

## 개인정보

이 서류들에는 주민등록번호 13자리, 계좌번호, 신분증 사본이 평문으로 들어 있습니다.

- **전 과정 로컬 처리.** 외부로 아무것도 보내지 않습니다.
- 결과 리포트에서 주민등록번호는 항상 가리고, 계좌번호는 뒤 4자리만 남깁니다 (`--mask basic`, 기본값).
- 결과를 외부에 공유해야 하면 `--mask strict` 로 성명·학번까지 가립니다.
- 샘플 서류는 저장소에 올리지 않습니다 (`.gitignore`).

   실제 파일에 `python -m app dump` 를 돌려 한 번 맞춰야 합니다 ([05번 문서](docs/05-implementation.md) 참고).

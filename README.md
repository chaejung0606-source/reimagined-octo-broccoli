# COSS 업무데스크 (ERP 청구서 다운로더)

여러 업무를 한곳에서 시작하는 데스크톱 앱입니다. 지금 되는 업무는 둘입니다.

- **청구서 받기** — 강원대 ERP 에서 승인된 청구서(지출요구 및 결의서) PDF 를 자동으로 받아, 내용에
  맞는 이름을 붙여 비목 폴더에 넣습니다. 이미 받은 건은 문서번호로 가려 건너뜁니다.
- **회의록 생성** — 회의 자료 폴더를 넣으면 정산용 회의록(.hwpx)을 만들어 그 폴더 안에 둡니다.
  이 PC 에 로그인된 **Claude Code** 로 돌아갑니다(별도 API 키 없음). 옛 '회의록 자동 작성 도구' 가
  이 앱 안으로 들어온 것입니다.

- **일반청구** — 지출 1건 = 폴더 1개. 폴더마다 **청구 종류**를 골라 ERP 일반청구 작성 화면에 채우고 **임시저장**까지
  합니다. 검토 후 **신청은 직접** 합니다.
  - **일반** — 자료 폴더(지출품의서 · 세금계산서 · 통장사본 등)를 AI 가 읽어 값을 뽑습니다. Claude Code 가 필요합니다.
  - **장학금** — 명단 엑셀 + `공통증빙` + `개별증빙` 폴더로 인건비(소득성 경비) 탭에 학생 한 명씩 넣습니다.
    앱이 확신하지 못하는 단계는 멈추고 묻습니다.
  - **출장비 · 카드** — 고르기 칸에 보이지만 아직 **준비 중**입니다.

앱을 열면 홈에서 업무를 고릅니다. 아래 독으로 업무 사이를 오가고, 위에는 파일 탐색기처럼
열어 둔 작업이 탭으로 남습니다([+] 로 새 업무). 설정과 업데이트는 오른쪽 위 톱니(⚙) 메뉴에 있습니다.

새 기능이나 디자인이 올라오면 **다시 내려받지 않아도** 됩니다. 앱을 켤 때 새 버전을 확인해
홈 위에 띠로 알려 주고, [지금 적용] → [새로고침] 이면 끝입니다. (앱 폴더 안의 저장소 정보로
받아오므로 폴더를 통째로 옮기거나 `.git` 을 지우면 안 됩니다.)

이 앱은 **받기만** 합니다. ERP 에 무언가를 입력하거나 제출하지 않습니다.
아이디·비밀번호는 어디에도 저장되지 않습니다. 매번 앱이 연 브라우저에서 직접 로그인합니다.

## 처음 한 번만 (설치)

**윈도우만 있는 PC 라면 — `설치.bat` 하나로 끝납니다.**

1. [`설치.bat`](설치.bat) 을 받아 더블클릭합니다. (동료에게는 이 파일 하나만 보내면 됩니다.
   또는 PowerShell 창에 아래 한 줄을 붙여 넣어도 같습니다.)
   ```powershell
   irm https://raw.githubusercontent.com/chaejung0606-source/reimagined-octo-broccoli/claude/expense-document-review-criteria-yzji9p/setup.ps1 | iex
   ```
   파이썬이 없으면 받고(winget → 안 되면 python.org), Git 이 없으면 설치 없이 쓰는 MinGit 을 받고,
   앱을 `사용자 폴더\AppData\Local\COSS업무데스크\app` 에 내려받아 준비까지 마칩니다.
   관리자 권한이 없어도 됩니다. 처음에는 10~15분쯤 걸리고, 끝나면 앱이 뜨고 바탕화면에
   **[COSS 업무데스크]** 아이콘이 생깁니다. 받다가 끊기면 다시 더블클릭하면 이어서 합니다.
2. 앱의 **[설정]** 에서 저장 폴더를 고릅니다 — 비목 폴더(01. 인건비 · 02. 장학금 …)가 바로 아래
   있는 폴더입니다. 예) `C:\Users\…\지출결의서\2026년도(e나라도움)`
3. 회의록 생성 · 일반청구 [내용 읽기] 를 쓰려면 **Claude Code** 를 설치하고 로그인합니다 — https://claude.com/claude-code
   앱을 켜면 홈 맨 위와 화면 맨 위 오른쪽의 **AI 단추**에 로그인 상태가 보입니다. 로그인이 필요하면 홈의 [로그인]
   (또는 AI 단추 → 로그인)을 누르면 로그인 창을 대신 열어 줍니다. 쓸 AI 는 **설정 → AI 플랫폼**에서 업무마다 고릅니다.

이미 파이썬이 있는 PC 는 예전처럼 이 폴더(또는 배포 zip)의 **`앱 실행.bat`** 을 더블클릭해도 됩니다.

## 사용 방법 (매번)

1. 바탕화면 아이콘으로 앱을 열고, 홈에서 **청구서 받기** 카드를 누릅니다.
2. **① 브라우저 열기** → 앱이 보관 폴더를 훑은 뒤 ERP 창을 엽니다.
3. **그 브라우저 창**에서 ERP 로그인 → [과제관리 → 과제정보 → 청구서] → 결의서내역 목록을 띄웁니다.
   (평소 쓰는 Edge/크롬이 아니라, 앱이 새로 연 창이어야 합니다)
4. 앱으로 돌아와 **② 목록 읽기** → 받을 건이 표에 뜹니다.
5. 숫자가 맞으면 **③ 모두 받기**. 처음이면 **앞 1건만 시험** 으로 흐름부터 확인하세요.
   대상이 수십 건 이상이거나 `⚠⚠` 경고가 뜨면 취소하고 저장 폴더를 확인하세요.

받은 파일은 **각 비목 폴더 바로 아래**에 들어갑니다. 예산관리 플랫폼에 올린 뒤 `업로드/` 폴더로
옮기세요. 앱은 `업로드/` 폴더를 읽기만 하고 절대 건드리지 않습니다.

## 회의록 생성

1. 홈에서 **회의록 생성** 을 누릅니다. 위 'AI 플랫폼' 줄에 **로그인됨** 이 떠야 합니다.
   (Claude Code 가 없으면 '사용 불가' 와 설치 안내가 뜨고 [작업 시작] 이 눌리지 않습니다.
   '로그인 필요' 면 화면 맨 위 오른쪽 AI 단추 → 로그인. 로그인을 마치면 단추가 알아서 초록 '로그인됨' 으로 바뀝니다.)
2. 회의 자료가 들어 있는 폴더를 화면에 **끌어다 놓거나** [회의 폴더 추가] 로 넣습니다.
   **폴더 1개 = 회의 1건.** 여러 회의가 하위 폴더로 나뉘어 있으면 [상위 폴더 추가].
3. [작업 시작]. 회의 1건에 수십 초~몇 분이 걸리고, 다른 탭으로 가도 작업은 이어집니다.
4. 끝나면 표의 '생성된 회의록' 을 더블클릭해 한글에서 엽니다. 회의록은 **그 회의 폴더 안에**
   `yyyy-mm-dd 요일 안건요약.hwpx` 로 저장되며 기존 파일은 덮어쓰지 않습니다(`-2`, `-3`).
   '보완요청' 칸에 적힌 것은 서류를 보완해야 하는 사항입니다(회의록 맨 위에도 붉게 적힙니다).

- 회의 자료는 선택한 AI 플랫폼(지금은 Claude)으로 전송됩니다. 참석자 실명이 들어 있으니 알아 두세요.
- 로그인이 풀렸거나 사용 한도에 걸리면 **1건만 실패하고 나머지는 '건너뜀'** 으로 멈춥니다.
  해결한 뒤 [작업 시작] 을 다시 누르면 됩니다(만들어진 회의록은 그대로 남습니다).
- 회의록의 문체·판단 기준은 [규칙 파일 열기] 의 `회의록규칙.txt` 에 있습니다. 저장만 하면 다음
  작업부터 반영됩니다. 옛 도구에서 규칙을 고쳐 두셨다면 그 `규칙.txt` 내용을 여기로 옮기세요.

### 파일명 형식

`비목번호_(지출예정일 YYMMDD) 적요_이체자_(금액).pdf`
예) `09_(261008) 2026년 사업단 정수기 임차료(9월)_코웨이(주)_(51,900).pdf`

[설정] 에서 비목 번호를 빼고 날짜로 시작하게(`(261008) …`) 바꿀 수 있습니다.

## 일반청구

1. 홈에서 **일반청구** → 청구 종류 '일반'(또는 '자동')으로 지출 폴더를 끌어다 놓습니다(폴더 1개 = 청구 1건). [내용 읽기] 를 누르면 AI 가 폴더를 읽어
   비목 · 증빙 · 일자 · 금액 · 적요 · 입금처 · 계좌를 뽑습니다.
2. 오른쪽 '청구 내용' 칸에서 값을 확인하고 틀린 곳을 고칩니다. 빨간 '확인:' 줄은 빠졌거나 어긋난 값입니다.
3. [브라우저 열기] → ERP 로그인 → 결의서내역 → **[일반청구]** 로 새 청구서 화면을 띄웁니다.
4. **[미리 보기]** 로 무엇을 넣을지 먼저 보고, '미리 보기만' 체크를 풀고 **[ERP 에 채우기]**.
5. ERP 화면에서 입금처(돋보기) · [예금주조회] · 첨부를 직접 넣고 값을 확인합니다.
6. 앱의 **[임시저장]** 을 누르면 앱이 ERP 의 [저장] 을 눌러 임시저장합니다. ERP 알림이 있으면 그대로 보여 줍니다.
7. ERP 에서 임시저장된 청구서를 검토한 뒤 **[신청]** 을 직접 누릅니다. 앱은 [신청] 을 절대 누르지 않습니다.

같은 폴더를 다시 채우려 하면 묻습니다. 뽑는 규칙(적요 형식 등)은 [규칙 파일 열기] 의 `일반청구규칙.txt` 에 있습니다.

## 일반청구 — 장학금

일반청구 화면에서 청구 종류를 **장학금**(또는 '자동')으로 두고 폴더를 넣습니다. 폴더는 이렇게 맞춥니다.

```
<지출 건 폴더>\
  2026학년도 (가)형 근로장학금 지급내역.xlsx   명단 엑셀 하나 (이름 · 학번 · 금액 열이 있으면 됩니다)
  공통증빙\    모든 학생에게 똑같이 붙일 파일 (지급 공문 · 명단 PDF …)
  개별증빙\    학생별 파일 — 파일명이나 하위 폴더 이름에 학생 이름 (예: 홍길동.pdf, 홍길동\근무일지.pdf)
```

1. 홈에서 **일반청구** → 위의 '청구 종류' 를 확인하고 폴더를 끌어다 놓습니다. 그 줄을 고르면 오른쪽 칸이 학생 표로 바뀝니다
   (학생 · 학번 · 금액 · 행 적요 · 첨부 수). 종류를 잘못 넣었으면 오른쪽 칸 위의 고르기 칸에서 바꿉니다.
   빨간 글(합계가 안 맞음 · 학번 없음 · 누구 것인지 모르는 파일)이 있으면 고친 뒤 [다시 읽기].
2. 대표적요(기본: `02_` + 명단 제목) · 지급예정년월을 확인합니다. 빼고 싶은 학생은 체크를 풉니다.
3. [브라우저 열기] → ERP 로그인 → 결의서내역 → **[일반청구]** 로 새 청구서 화면을 띄웁니다(인건비 탭은 앱이 누릅니다).
4. **[미리 보기]** 로 학생마다 무엇을 넣을지 보고, '미리 보기만' 체크를 풀고 **[ERP 에 넣기]**.
5. 앱이 학생마다 비목 · 소득구분(장학금) · 소득자(학번이 맞는 사람 하나일 때만) · 금액 · 적요 · 첨부를 넣고 [저장] 합니다.
   소득자가 애매하거나 예금주조회 결과가 없거나 계좌가 명단과 다르면 **노란 띠**로 멈춥니다. ERP 에서 처리하고 [계속].
6. 다 끝나면 ERP 에서 청구내역을 검토하고 **[신청]** 을 직접 누릅니다.

적요 꼴은 [적요 규칙 열기] 의 `장학금규칙.txt` 에서 바꿉니다((나)형 TA 는 `대표적요(이름_학번_강좌명)`).

## 문제가 생기면

- 받기 화면 아래 **진행 기록**에 어디까지 됐는지 나옵니다. [로그 파일 열기] 로 `_실행로그.txt` 를
  열어 담당자(임채정)에게 보내 주세요.
- "결의서내역 목록을 찾지 못했습니다" → 앱이 연 브라우저 창에서 목록을 띄웠는지 확인
- 주황색 띠 "상세화면이 멈춰…" → 그 브라우저에서 다시 로그인 → 목록 → [계속] (같은 건부터 이어받습니다)
- 처음부터 다시 받고 싶으면 [설정 → 기록 → 폴더 열기] 에서 `_받은기록.json` 을 삭제
  (보관 폴더에 있는 건은 그래도 건너뜁니다)
- 회의록 화면이 "사용 불가" → Claude Code 를 설치했는지, 명령 프롬프트에서 `claude --version` 이
  되는지 확인. 설치 직후라면 컴퓨터를 다시 시작한 뒤 [다시 확인].

## 업데이트

새 기능이 올라오면 홈 위의 띠 또는 오른쪽 위 톱니(⚙) → **[업데이트]** 에서 [업데이트 적용] → **[새로고침]**.
새로고침을 누르면 창이 닫혔다가 새 버전으로 다시 열립니다(2~3초) — 앱을 직접 껐다 켤 필요가 없습니다.
설정과 받은 기록은 앱 폴더 밖(`사용자 폴더\.claim-downloader`)에 있어 업데이트해도 그대로 남습니다.

## 개발

[`CLAUDE.md`](CLAUDE.md) 에 ERP 화면 구조 · 알려진 함정 · 안전 원칙이 정리되어 있습니다.
남은 일은 [`docs/roadmap.md`](docs/roadmap.md).

```bash
pip install -e ".[gui,excel,dev]"
python -m pytest -q
python -m claim_downloader.ui.app      # 데스크톱 앱
python -m claim_downloader --limit 1   # 콘솔에서 1건 시험
python -m claim_downloader --structure # 진단 모드: 열린 ERP 화면의 입력 요소를 _화면구조.txt 로 (읽기만)
```

새 화면(출장비 · 카드 등)을 자동화하려면 먼저 그 화면의 구조가 필요합니다. 앱의 청구서 받기 →
[진행 기록] 탭 구석 **[화면 구조 저장]** 을 그 화면이 열린 상태에서 누르고, 생긴 `_화면구조.txt` 를
담당자에게 보내 주세요. 값은 넣지 않은 빈 작성 화면에서 누르는 것이 좋습니다.
